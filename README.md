# DiamondSquare

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 18.0.6.

Este proyecto implementa la generación de terrenos utilizando el Algoritmo Diamond-Square, un método eficiente para crear mapas de altura realistas y visualizaciones de terrenos en 2D. Es ampliamente utilizado en aplicaciones de juegos, simulaciones y gráficos por computadora.
